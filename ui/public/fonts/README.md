# Coronet

The dashboard's display font is **Coronet** (headings and the wordmark). Coronet is a
commercial typeface, so it is not bundled in this repository.

The page uses it automatically if either:

1. Coronet is installed on the presenting computer (any of the names *Coronet*,
   *Coronet Bold*, *Coronet LT Std*), or
2. you place a licensed copy here as `Coronet.woff2`, `Coronet.woff`, `Coronet.otf`
   or `Coronet.ttf`.

Font files in this folder are git-ignored, so a licensed copy is never published by
accident. Without Coronet the page falls back to Pinyon Script (SIL Open Font
License, bundled through `@fontsource/pinyon-script`).
